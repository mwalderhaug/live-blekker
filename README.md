# Live-blekker

Akkordblekker for live-spilling på iPad: én sang per skjerm, sveip mellom sangene, Live-modus uten redigering.

Appen: https://mwalderhaug.github.io/live-blekker/

- Selve appen ligger her (offentlig, ingen sanger).
- Blekkene ligger i et privat repo og hentes med en nøkkel som bare ligger på enheten.
- Legg den til på Hjem-skjermen på iPaden (Del → «Legg til på Hjem-skjerm»), så åpner den i fullskjerm og virker uten nett.
